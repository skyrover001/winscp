ARCHITECTURE
===============================================================================

Connection Flow:
  1. User selects HTTP protocol in login dialog
  2. Enters: Username, Password, Backend URL
  3. On connection:
     a. THttpProxyFileSystem::Open() called
     b. DoHttpLogin() - POST to {BackendUrl}/login
     c. Receive session token
     d. ConnectWebSocket() - Connect to ws://{BackendUrl}/ws_proxy?token=...
     e. Backend creates TCP tunnel to SFTP server
     f. All SFTP commands flow through WebSocket

Protocol Hierarchy:
  TCustomFileSystem (base)
    └── THttpProxyFileSystem (new)
          ├── DoHttpLogin() - HTTP authentication
          ├── ConnectWebSocket() - WebSocket connection
          └── SendWebSocketData/ReceiveWebSocketData - Data transfer
